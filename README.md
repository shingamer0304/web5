# SHIN // TACTICAL PORTFOLIO

Interactive portfolio rebuilt from scratch with a sci-fi industrial interface.

## Included
- Cinematic construction-style boot sequence
- Animated grid, scanlines, particles and orbital background
- Tactical crosshair cursor and hover targeting
- Scroll reveal and encrypted heading animation
- 3D tilt and magnetic interactions
- WebAudio UI feedback generated in-browser
- Interactive skill tree
- Classified project modal
- Target acquisition mini-game
- Normal Mode / Emergency Override theme switch
- Responsive layout and reduced-motion support

## Stack
HTML5 / CSS3 / Vanilla JavaScript / Canvas / WebAudio API
